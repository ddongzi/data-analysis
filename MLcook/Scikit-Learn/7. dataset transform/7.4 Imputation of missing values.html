6.4.1. Univariate vs. Multivariate Imputation#

  • Univariate Method: imputers values in the i-th feature dimension using only non-missing values in i-th dimension.(SimpleImputer)

  • Multivariate Method: use the entire set to estimate the missing values(IterativeImputer)

6.4.2. Univariate feature imputation#

SimpleImputer provides some basic strategies : constant, statistics(mean,median,mode).

import numpy as np
from sklearn.impute import SimpleImputer
imp = SimpleImputer(missing_values=np.nan, strategy='mean')
imp.fit([[1,2],[np.nan,3],[5,6]])

6.4.5. Keeping the number of features constant#

By default, sklearn will drop fully empty features columns.

imp = SimpleImputer()
imp.fit_transform([

    [np.nan,2],
    [np.nan,3]
