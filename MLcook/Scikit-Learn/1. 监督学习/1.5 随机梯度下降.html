随机梯度下降： 用于 线性模型 回归/分类的 损失函数 的 最优化。 (如 svm, logistic)

  • 一些稀疏特征 的场景， 如自然语言 文本

  • 迭代快;

  • 参数增多？; 对特征缩放敏感？

在sklearn中， SGDClassifier(loss='log_loss') 等价于logistic分类使用 SGD优化。
SGDRegressor(loss='squared_error', penalty='l2') 等价于 linear ridge 回归 使用SGD优化· SGDClassifier(loss="hinge", penalty="l2",.. ) 等价于 SVM linear核分类 使用SGD优化

分类#

from sklearn.linear_model import SGDClassifier
X = [
    [0, 0],
    [1, 1]
]
y = [0, 1]
clf = SGDClassifier(loss='hinge', penalty='l2', max_iter=5)
clf.fit(X, y)
