warm_start=True model will reuse last solutions(coef) as initial value. intercept_scaling=10000.0： adjust the regularization impact on the bias. The larger is scaling factor, the less is impact.

import numpy as np
from sklearn.linear_model import LogisticRegression

clf = LogisticRegression(
    penalty='l1',
    solver='liblinear',
    tol=1e-6,
    max_iter=100000,
    warm_start=True,
    intercept_scaling=10000.0
)

l1_min_c 计算给定(X,Y,损失函数)的最小 正则化强度参数C。

  • 返回值表示，恰好能够让所有特征系数不为0的最小值。 即小于返回值C，所有权重系数都为0，模型失效。 大于返回值，至少有一个特征系数非0

✅计算原理

from sklearn.svm import l1_min_c 
min_c = l1_min_c(X,y,loss='log') 
cs = min_c* np.logspace(0,10,16)

print(cs.min(), cs.max(),min_c)
