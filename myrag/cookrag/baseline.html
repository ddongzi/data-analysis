分块#

  1. MarkdownHeaderTextSplitter基于文档结构的分块。 我们通过header等分割，基本只有3级。

  • 结果依然是docuemtn

  • 这是不够的，因为很长内容，需要二次分块

  1. RecursiveCharacterTextSplitter 指定块大小

综上我们得到一个分块器：

from langchain_text_splitters import MarkdownHeaderTextSplitter
from langchain.text_splitter import RecursiveCharacterTextSplitter

def splitter_documents(documents: list[Document]) -> list[Document]:
    """ 对一些document分块 """
    headers_to_split_on = [
        ("#", "Header 1"),
        ("##", "Header 2"),
        ("###", "Header 3"),
    ]
    markdown_splitter = MarkdownHeaderTextSplitter(headers_to_split_on)
    
    text_splitter = RecursiveCharacterTextSplitter(
        separators = ["\n\n", "\n", "。", "，", " ", ""],  # 分隔符优先级
        chunk_size = 200,
        chunk_overlap=10
    )
    all_sections = []
    for doc in documents:
        sections  = markdown_splitter.split_text(doc.page_content)
        all_sections.extend(sections)

    chunks = text_splitter.split_documents(all_sections)

    # page_content会丢失层级信息，只保留内容. 
    # 这导致一勺盐不知道是红烧肉还是豆腐
    # 需要手动为其注入
    for chunk in chunks:
        prefix = ""
        h1 = chunk.metadata.get('Header 1', '无')
        h2 = chunk.metadata.get('Header 2', '无')
        h3 = chunk.metadata.get('Header 3', '无')
        prefix = f"主题: {h1} > 章节: {h2} > 细节: {h3}\n内容: "
        chunk.page_content = prefix + chunk.page_content 
    return chunks

必备原料和工具

  • 原料： 鸡爪、姜、料酒、大葱、大蒜、小米辣、洋葱、生抽、蚝油、黑醋（推荐陈醋）、白糖、盐、花椒油、香菜、柠檬、折耳根。

操作步骤

  • 加水没过鸡爪。

  • 大火煮开，中途可撇去浮沫。

  • 水沸腾后，继续煮10分钟。

  • 关火，捞出鸡爪，沥干水分，用凉水冲洗干净，放入盆中。

2. 去骨（可选步骤，此步骤约需2小时）

  • 将鸡爪放入冰箱冷冻层冷冻20分钟。

  • 将鸡爪移至冰箱非冷冻层，分批（例如10个一批）取出进行去骨。

操作步骤

  1. 预处理：

    • 猪五花肉按上述切块，生姜切片，葱白备好。

    • 烧开一锅水备用。

    • 如果使用豆皮，切条备用（可选）。

  2. 开始制作：

    • 锅中加入料酒（5ml），将猪五花肉翻炒至上色。

    • 加入烧好的开水，炖煮 40 分钟（如果肉块切得过大，可适当延长炖煮时间）。

    • 放入生姜（2 片）、香叶（3 片）、八角（2 个），盖上锅盖煮至沸腾。

    • 省略鹌鹑蛋：沸腾后，只加入豆皮（如果使用），开中小火继续炖煮 40 分钟（中途可适当翻搅防止粘锅）。

    • 打开锅盖，待汤汁快收干时，开大火收汁（切记不可完全收干）。

    • 最后加入盐（2-3g），翻炒均匀即可出锅。

关键说明

  • 由于鹌鹑蛋是可选配料，省略后不影响其他步骤，您可根据喜好决定是否使用豆皮。
